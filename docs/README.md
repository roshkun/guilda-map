# Documentos

Coloque aqui os documentos da guilda (.md, .pdf, imagens...) e aponte para eles em
`data/markers.json`, no campo `docs` de cada marcador:

```json
"docs": [{ "title": "História da cidade", "url": "docs/historia-alvorada.md" }]
```

Links externos (Google Docs, Notion, Wix...) também funcionam.
